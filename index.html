⚙️ Supabase Setup

1. Create free account at supabase.com
2. Create a new project
3. Go to Settings → API → copy Project URL and anon key
4. Open uniclean_v6.html in a text editor
5. Replace YOUR_SUPABASE_URL and YOUR_SUPABASE_ANON_KEY at the top of the file
6. Run the SQL below in your Supabase SQL Editor to create the table 
CREATE TABLE reports (
  id BIGSERIAL PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  category TEXT NOT NULL,
  description TEXT,
  photo_url TEXT,
  video_name TEXT,
  latitude FLOAT,
  longitude FLOAT,
  coordinates TEXT,
  location_source TEXT,
  status TEXT DEFAULT 'Open',
  date_str TEXT,
  time_str TEXT
);
-- Allow public inserts (no login required)
ALTER TABLE reports ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public can insert" ON reports FOR INSERT WITH CHECK (true);
CREATE POLICY "Public can read" ON reports FOR SELECT USING (true);
CREATE POLICY "Public can update status" ON reports FOR UPDATE USING (true);
About UniClean

What is UniClean?

UniClean is a community environmental reporting platform. Citizens document pollution, illegal dumping, and environmental damage. Reports are pinned on a live public map — creating visibility, accountability, and action.

How it works

  • Tap Report — no login needed
  • Take or upload a photo of the issue
  • Select category and write a short description
  • GPS coordinates captured automatically
  • Report goes live on the public map instantly

Built for pilots

Designed for municipalities, trade fairs, schools, community organisations, and environmental campaigns. Share the QR code — residents scan and report in under 60 seconds.
