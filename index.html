⚙️ Supabase Setup

1. supabase.com → New project
2. Settings → API → copy Project URL + anon key
3. Replace values at top of this file
4. Run the SQL below in Supabase SQL Editor 
CREATE TABLE reports (
  id BIGSERIAL PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  report_id TEXT,
  category TEXT NOT NULL,
  severity TEXT DEFAULT 'Medium',
  description TEXT,
  photo_url TEXT,
  video_name TEXT,
  latitude FLOAT,
  longitude FLOAT,
  coordinates TEXT,
  location_source TEXT,
  stage TEXT DEFAULT 'Spotted',
  claimer_name TEXT,
  claimer_entity TEXT,
  claimed_at TIMESTAMPTZ,
  resolved_at TIMESTAMPTZ,
  resolution_note TEXT,
  support_count INT DEFAULT 0,
  escalated BOOLEAN DEFAULT false,
  date_str TEXT,
  time_str TEXT
);
ALTER TABLE reports ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Public insert" ON reports FOR INSERT WITH CHECK (true);
CREATE POLICY "Public read" ON reports FOR SELECT USING (true);
CREATE POLICY "Public update" ON reports FOR UPDATE USING (true);
About UniClean

See it. Report it. Resolve it.

UniClean is a community environmental reporting platform by RE-versal. Citizens document pollution, illegal dumping, and environmental damage. Reports are pinned on a live public map — creating visibility, accountability, and action.

The Five Stages

  • 🐠 Spotted — Issue photographed and GPS-pinned
  • 🤝 Claimed — Individual, NGO, business or government publicly commits
  • 🔨 In Progress — Cleanup updates posted live
  • ✅ Resolved — After-photos confirm cleanup. Record is permanent.
  • ⚠️ Unclaimed — Auto-escalated to admin if no one acts in time

Built for pilots

Municipalities · Trade fairs · Schools · NGOs · Community campaigns. Share the QR code — anyone scans and reports in under 60 seconds. No login. No app.
